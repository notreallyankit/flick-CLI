# **Flick CLI – Serverless File Transfer**

**Flick CLI** is a lightweight, **serverless file transfer tool** that lets you securely and efficiently transfer files between devices on the same network using a **hub-PC model**. Built entirely in Python, it leverages a **command-line interface** for simplicity and speed.

---

## **__Features__**
- **Serverless:** No need for a central server; the hub-PC manages transfers.  
- **Cross-device transfers:** Send files between computers on the same network.  
- **Threaded communication:** Handles multiple transfers concurrently.  
- **Intuitive CLI:** Built with `Typer` for easy commands and usage.
